# 🔐 Password Security Toolkit

## Overview
Password Security Toolkit is a cybersecurity web application developed using Python and Flask. It helps users create secure passwords by checking password strength in real time and providing useful security features.

## Features
- 🔐 Password Strength Checker
- 📊 Live Strength Meter
- 📈 Strength Percentage
- 👁 Show/Hide Password
- 🎲 Strong Password Generator
- 📋 Copy Password
- 🌙 Dark Mode
- 📜 Password History
- ✅ Live Password Validation
- 📱 Responsive Design

## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript
